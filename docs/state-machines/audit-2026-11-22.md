# Implicit state-machine audit — 2026-11-22

Read-only audit of `src/` against the rule in the Android catalog
(`~/repo/telly/docs/state-machines.md`, "The rule"): ONE mode = ONE discriminated
union written in ONE place; no boolean + nullable + counter trios; no consume-once
flags set in one file and read in another; no sentinel encodings; timers are part of
the state; every machine has a catalog row and every `explicit` row's owner carries
`// @stateMachine('<row>')`.

Method: every non-test `.ts`/`.tsx` under `src/` was read (≈500 files, ≤100 logic
lines each); the grep seeds were `useRef<boolean|useState<boolean|pending|armed|
consumed|let *: boolean|= false;|setTimeout|setInterval|useState(|useRef(` plus
module-level `let`. Every hit was read in context, then compared with the web catalog
(`docs/state-machines.md` + `docs/state-machines/*.md`, 36 rows, all `explicit` or
`guarded`) and with the Android catalog (36 rows + a "Known gaps" list). The repo was
at the state found on disk on 2026-11-22 (not a git checkout); the Android repo was at
`a09b8ce` (2026-11-19).

This file is documentation only. Its tables deliberately use column counts the gate
regex in `scripts/check-state-machines.mjs` does not parse as catalog rows, and status
words are always back-ticked, so the gate ignores it.

## 1. Implicit machines found (not catalog rows)

Priority: **P1** = can double-fire a persisted action, drop or double a key, leave a
timer/engine running after its mode ended, or show two layers at once. **P2** = two
sources of truth that can disagree on screen, or a timer/flag that outlives its mode
without a visible failure today. **P3** = guarded or pure, same split as Android;
listed so nobody re-discovers it.

## 3. Prioritised fix list (highest UX risk first)

1. **F1 PIN entry** — one `PinEntryState` owner in `src/core/ui/pinEntry.ts`; `Submitted` swallows OK/digits until the host resolves; merge the two `pinEntry.ts` modules; the five prompts render it. Add an e2e step that types four digits AND presses Enter on a `Block channel` PIN and asserts the flag flipped exactly once. Row `PIN entry` (`explicit`). Why first: a persisted flag can double-flip from one normal remote gesture.
2. **F5 Background refresh** — remove the `started` ref; own the interval in a state (`Idle · Running(timer)`) via the F10 lease. Why: with `StrictMode` on, the quarter-hour EPG/playlist refresh is dead in every dev session and would die in prod on any dependency change — a silent "engine stopped" for data.
3. **F2 Startup key queue** — one `StartupKeyQueue` (`Holding · Replaying · Live`, one key per commit) replacing the guide/playback/search copies; delete the shared `NO_KEYS` singleton and `GuideController.rowsLoaded`. Row `Startup key queue` (`explicit`). Why: three replay semantics for one "never drop a key" promise.
4. **F4 + F10 Shared lease with async start** — one `RefCount<T>` (`Free · Starting(cancelled) · Held(n, resource)`) replacing `SharedPlayerEngine` internals, `LeaseHolder`, `SharedTicks`, and the module-level `let`s in `autoBackupEngine.ts`; `recordingRuntime.ts` stops the scheduler even when released during start. Row `Shared resource lease` (`explicit`). Why: a scheduler can outlive its host and run twice.
5. **F3 Recordings library** — `LibraryMode` union + `STOPPING` as a persisted `RecordingStatus`; delete `stoppedIds`. Rows: `Recordings library` (`explicit`), extend `Recording row`. Why: two layers representable at once; closes an Android known gap on the web side first.
6. **F6 VOD pause/active duplication** — derive from `engine.paused` and `VodStage`. Why: the pause icon and the real pause can disagree after `Ended`.
7. **F12 Channel-options dialog** and **F16 Custom-recording form** — carry the dialog/form inside the layer variant so the layer union is the ONE owner of "what is on top". Why: stale sub-layers resurface after `menu.reset()`/BACK.
8. **F13 Catch-up pending seek** — move the latch into `CatchupState`; update the `Catch-up mode` row text on the web (states differ from Android).
9. **F7 / F9 / F11 bool+timer pairs** (`VodTransportVisibility`, `ReminderPopupController`, `GuideHint`) — small unions with the timer inside; add `guarded` rows `VOD transport visibility`, `Reminder popup`, `Guide hint` on BOTH platforms (Android has the identical splits).
10. **F8 / F14 / F15 lifecycle bits beside unions** — `Exited` route in the `Navigator`; `Restoring` in `RestoreOffer` (both platforms); VOD visit lifecycle owned by the holder.
11. **Catalog hygiene** — (a) rename/fold `Catch-up PIN stash` into `Blocked-channel gate` to restore same-name parity, or add the row to Android; (b) add a web "Known gaps" section with `implicit` rows for F9's `handled` and anything not fixed above; (c) port the Android gate's checks 3 and 4 (overlay funnel, uncited `consume*()`/`pending`) to `scripts/check-state-machines.mjs` with the parser carve-out; (d) add rows for already-shaped unions that lack one (`Wizard inline editor`, F27).
12. **P3 leftovers** (F17–F29) — convert opportunistically when the file is touched; F17 only together with Android.
