Web honesties (see the decisions log): captures live in the Origin Private
File System inside the browser profile and count against its storage quota;
the scheduler ticks only while the tab is open and visible (no alarm
wakeups, as on Android — the settings pane says so); a tab closed mid-capture
leaves the row RECORDING until the next start finalizes it from the file size.
