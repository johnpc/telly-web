<h1 align="center">telly-web</h1>
<p align="center"><b>An open-source, TiviMate-style IPTV player for the web — remote-first, keyboard-only navigable.</b></p>

Web port of [telly](https://github.com/johnpc/telly) (Android TV) with feature parity. Work in progress — see [CLAUDE.md](CLAUDE.md).
